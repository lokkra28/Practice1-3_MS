# Практические работы по машинному обучению и глубокому обучению

ФИО: Якушенко Михаил Сергеевич

## Практическая работа № 1. Классическое машинное обучение

1. Линейная регрессия - прогнозирование прочности бетона на сжатие по составу смеси и возрасту образца. Датасет: UCI Concrete Compressive Strength.
2. Логистическая регрессия - бинарная классификация банкнот на подлинные и поддельные по числовым характеристикам. Датасет: UCI Banknote Authentication.
3. Дерево решений - классификация автомобилей по цене, стоимости обслуживания, вместимости, размеру багажника и безопасности. Датасет: UCI Car Evaluation.
4. Случайный лес - классификация грибов на съедобные и ядовитые по физическим характеристикам. Датасет: UCI Mushroom. Работа носит учебный характер; предсказания модели нельзя использовать для определения безопасности реальных грибов.

## Практическая работа № 2. Нейронные сети

1. Полносвязная нейронная сеть (FCN / MLP) - классификация двух сортов риса (Cammeo и Osmancik) по морфологическим признакам. Датасет: UCI Rice.
2. Сверточная нейронная сеть (CNN) - распознавание изображений одежды по десяти категориям. Датасет: Fashion-MNIST.
3. Рекуррентная нейронная сеть (RNN / LSTM) - определение положительной или отрицательной тональности отзывов о фильмах. Датасет: IMDB Large Movie Review Dataset.

## Практическая работа № 3. Fine-Tuning Transformer

Дообучение DistilBERT для многоклассовой классификации эмоций в коротких англоязычных текстах. Используется модель distilbert-base-uncased и датасет dair-ai/emotion с шестью категориями: sadness, joy, love, anger, fear и surprise. Выполняются токенизация текстов, Fine-Tuning модели, выбор лучшей контрольной точки по валидационной F1-score и итоговая оценка на тестовой выборке.
